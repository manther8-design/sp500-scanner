# Smart Financial & Accounting ERP

نظام ERP متكامل للإدارة المالية والمحاسبية والموارد البشرية والرواتب والتحليل المالي، مع محرك معادلات مرن (Smart Payroll Rules Engine) ودعم تهيئة أنظمة العمل السعودية.

## الميزات المنفذة

- محاسبة القيد المزدوج: دليل حسابات، قيود، ترحيل، عكس قيود
- مبيعات / مشتريات / مصروفات / نقدية وبنوك
- موارد بشرية: ملفات موظفين، حضور، إضافي، إجازات، سلف، حوافز
- مسير رواتب مرتبط بالمحاسبة تلقائياً عند الاعتماد والترحيل
- محرك معادلات قابل للإصدار مع تجميد اللقطات التاريخية
- نهاية خدمة بمعادلات قابلة للتهيئة
- لوحة تحكم وتحليل مالي ومساعد ذكي يعتمد على بيانات النظام فقط
- تعدد الشركات/الفروع وصلاحيات RBAC ومسار تدقيق

## التشغيل

```bash
npm install
npx prisma db push
npm run db:seed
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)
